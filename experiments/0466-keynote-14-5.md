# 0466: New presentations in Keynote 14.5

**Status:** run

Pages and Numbers 14.5 write the same format as 15.4 ([0461](0461-new-documents-in-14-5.md), [0464](0464-recipes-rerun-in-14-5.md)). Keynote 14.5 is now installed too. This experiment reruns, unchanged, the AppleScript recipes of the early Keynote experiments, and compares each 14.5 presentation with the one Keynote 15.4 made from the same recipe.

| Date | 2026-11-24 |

| Compared with | Each experiment's own 15.4 sample, with [`recipes/0461-compare-structure.py`](../recipes/0461-compare-structure.py): 16 pairs |

## Observation

Every recipe but 0196 ran unchanged. 0196 didn't compile: Keynote 14.5's AppleScript dictionary has every transition effect 0196 uses except `radial wipe`, so the recipe ran without that one effect and made 37 slides instead of 38. The 37 transitions carry the same identifiers as in the 15.4 presentation (`apple:dissolve` and so on, [0196](0196-every-transition.md)).

In all 16 pairs, the same parts, the same number of records of each type but those below, the same version in header field 2.2 for every type both releases write, and the same top-level fields for every type but two. The differences, besides UUIDs:

| | 15.4 | 14.5 |
| --- | --- | --- |
| `Properties.plist` | `fileFormatVersion` `26.4.0`, the two flags 0461 found | `14.4.1`, the one combined flag |
| `BuildVersionHistory.plist` | `Template: 21_BasicWhite (dev/15.4)`, `M15.4-7051.0.79-2` | `Template: 21_BasicWhite (13.2)`, `M14.5-7045.0.17-4` |
| `CalculationEngine.iwa` | the empty type-4011 record, named by field 15 of type 4000 | neither |
| Slide nodes (type 4, `Document.iwa`) | field 32, 0 | no field 32 |
| `Data/blankMoviePosterImage-8945.png` | not in the package: data 8945 is an app resource, with a type-11014 colour ([0294](0294-resource-colours.md)) | stored in the package, so its entry has a stored file name (field 4) and no colour: one type-11014 record fewer in `Metadata.iwa` |
| Master thumbnails `Data/mt-UUID-N.jpg` | 16, with one set of UUIDs | 16, with another: no UUID in common with 15.4, the same set in every 14.5 presentation |
| `DocumentStylesheet.iwa` | 225 paragraph styles (type 2022) | 226: one more, unnamed |

Field 32 is 0 on every one of the 6,006 slide nodes in the 15.4 presentations under `samples/` and absent from every 14.5 one.

The extra paragraph style is a variation of *Liten infotekst* (`text-15-paragraphstyle-Caption Small`, field 1.3) that sets the size to 56 points. 17 empty text records (type 2001) on Basic White's template slides refer to it in field 5, where 15.4 refers to *Brødtekst* (Body): 15.4 has 26 such records on *Brødtekst*, 14.5 has 9 on *Brødtekst* and 17 on the new style. Every other template-slide text refers to the same named style in both.

The number of slide thumbnails (`st-UUID-N.jpg`) differs by one in two pairs (0067, 0068), in opposite directions, and 0196 has seven in 14.5 against one in 15.4: these follow which slides had been drawn before saving rather than the release, as far as can be told.

## Conclusion

Keynote 14.5 writes the same format as 15.4: slides, slide nodes, titles, notes, layouts, charts, text boxes, document settings, transitions, styles and placeholders are laid out the same way, down to the record versions. Besides the differences every 14.5 document has ([0461](0461-new-documents-in-14-5.md)), the 14.5 Keynote differs in four small ways:

- 15.4 adds field 32, so far always 0, to every slide node. A reader can ignore it. Whether 15.4 needs it in a file it opens is untested, since 15.4 is no longer installed.
- 15.4 keeps the blank movie poster image as an app resource, and 14.5 stores it in the package. A reader that finds images by their data entry, as the spec says, handles both.
- Basic White's master thumbnails have different UUIDs in each release. They stay the same in every presentation one release makes from the theme.
- The 14.5 Basic White template has one more unnamed paragraph style, used by empty texts on its template slides. As with Numbers' *Table Title 1* ([0464](0464-recipes-rerun-in-14-5.md)), a reader finds styles by reference and needs nothing for it.

The one difference in what can be scripted is the radial wipe transition, which 14.5's dictionary doesn't name. Whether 14.5 reads it from a 15.4 file is the next experiment's question.

## Confidence

*Confirmed*: for the 16 presentations of these recipes, Keynote 14.5 writes the same structure as 15.4, apart from the differences listed. *Unknown*: what slide-node field 32 is for.
