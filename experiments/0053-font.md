# 0053: A different font

**Status:** run

[0010](0010-alignment.md) read the font name (field 11.5) from the Body style. This experiment changes only one word's font, to confirm field 11.5 on its own and check the style rule of [0033](0033-style-resolution.md) for it.

## Setup

| | |
| --- | --- |
| Pages | 15.4 (build `M15.4-7051.0.79-2`) |
| macOS | 26.5.2 (25F84) |
| Date | 2026-11-09 |
| Baseline | Experiment [0008](0008-runs-and-shared-styles.md), `middle.pages` |

## Recipe

```bash
mkdir -p samples/0053
osascript recipes/0053-pages-font.applescript "$PWD/samples/0053/font.pages"
```

The recipe sets the body text to `one two three` and the `font` of word 2 to `Georgia`. Each word's font and size were then read back through Pages, as in 0033.

## Observation

The character-style runs have `two` (4–7) on a new type-2021 style, 1732647, with one property:

```
10: 1
11: { 5: "Georgia" }
```

| Word | Pages reports | Predicted by the 0033 rule |
| --- | --- | --- |
| one | HelveticaNeue, 11 | same |
| two | Georgia, 11 | same |
| three | HelveticaNeue, 11 | same |

## Conclusion

Field 11.5 of a character style is the font name, and a style can set it alone: the size comes from the paragraph style. The style rule holds for fonts set this way.

## Confidence

*Confirmed*: field 11.5 is the font name ([0010](0010-alignment.md) and this experiment).
