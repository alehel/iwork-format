# 0271: A dynamic background

**Status:** run

Keynote can give a slide a moving, generated background (*Dynamiske* in the Slide tab). This experiment turns one on, to see whether the motion is stored as a video, an image or parameters.

## Setup

| | |
| --- | --- |
| Keynote | 15.4, in Norwegian |
| macOS | 26.5.2 (25F84) |
| Date | 2026-11-09 |
| Baseline | `samples/0271/plain.key`, a new presentation |

## Recipe

1. Make a new presentation:
   ```bash
   osascript -e 'tell application "Keynote" to make new document'
   ```
2. In the Format sidebar's Slide tab, click Dynamic (*Dynamiske*) under Background (*Bakgrunn*). Keynote applies its first preset, a shifting rainbow gradient. The sidebar shows an angle of 352.7°, a scale of 1.40 and a speed of 41.67.
3. Save it as `samples/0271/dynamic.key`.

## Observation

The package gains `Data/motionBackground-9091.jpeg`, a 36-kilobyte still of the background.

The slide's style reference (field 1) names a new slide style (type 9) whose property 11.1 is a fill with field 3, an image fill:

```
3: { 2: 3,  4: 1920 × 1080,  6: { 1: 9091 },  8: 0,  9: a colour }
200: { 1: { 1: 2651723 } }
```

Record 2651723 is a type-26 style in the stylesheet:

```
1:  { 1: "Rainbow", 2: "motionBackground-0-motionBackgroundStyle" }
11: { 1: "KNGradientLinearBase",
      3: { 2: { … six stops at 0, 0.2, 0.4, 0.6, 0.8, 1, each a colour, a position and 0.5 … } },
      11: 128.0,  30: 0.0,  32: 0.857,  44: 0.5,  64: 1.4205,  70: 41.57,
      86: 33.7,  91: 0.973,  92: 1.5,  95: 1.5 }
12: { 1: 9091 }
```

## Conclusion

A dynamic background has two parts:

- **A still image (field 3 of the slide's fill):** the data file `motionBackground-…`, stretched to the slide's 1920 × 1080. A reader that can't animate shows this image, so the slide looks right.
- **The generator (field 200 of the fill):** it names a type-26 motion background style. That style holds the generator's name (`KNGradientLinearBase`), its colour stops in the same layout as a gradient fill ([0260](0260-gradient-fill.md)), and parameters as doubles. Field 64 (1.42) is the scale and field 70 (41.6) the speed the sidebar shows, rounded. The stored values differ slightly from the sidebar's, so the sidebar probably rounds them. The angle of 352.7° isn't among the stored values as given. It is probably derived from another value, or stored in radians or as a fraction of a turn.

Named presets such as `Rainbow` are styles in the stylesheet, like shape and text styles. The still is the key fact for readers: the animation is generated by Keynote and isn't stored as video.

## Confidence

*Likely*:

- A dynamic background is a slide fill holding both a pre-rendered still and a type-26 generator style.
- Fields 64 and 70 are the scale and speed.

*Unknown*: the other parameters, including the angle.
