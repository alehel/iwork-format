Pages#

What is specific to Pages documents: page setup, sections, and headers and footers. The container is described in 1. Container and the body text in 2. Text. Every finding links to the experiments that support it, with a confidence level as defined in CONTRIBUTING.md.

Describes documents from Pages 16.0. Most of the experiments cited ran with 15.4, which writes the same format; Releases says how 16.0 was checked against it.

Page setup#

Pages keeps its page setup in the document root (object 1, type 10000). All lengths are in points, as floats. Likely (0027, 0028)

FieldHolds
30, 31Paper width and height (confirmed by writing them, 0318)
32, 33, 34, 35Left, right, top and bottom margins (confirmed by writing them, 0318, 0326, 0366)
36, 37Header and footer distance from the page edge (confirmed by writing them, 0366). A header or footer that reaches past the margin pushes the body away from it
43Printer name
40Change tracking: 1 while it is on. Fields 16 and 17 then name the current editing session, a type-2062 record (0269)
42Orientation: 0 portrait, 1 landscape; 30 and 31 are already swapped (0155). The page is drawn from 30 and 31 alone: writing 42 doesn't turn it, and Pages doesn't make the two agree (confirmed by writing, 0367)
44Paper name, such as iso-a4; empty for a custom size, as in the book templates, which make ordinary documents (0198)
15.9The identifier of the template the document came from, such as Application/Blank/ISO (0155)
48Only in page-layout documents: names a page template (type 10017). Their body text record is empty. (0156)

Headers and footers#

Header and footer text is in type-2001 records, like the body. They are reached through the body's section runs (field 17), which point at a section (type 10011). Fields 23, 24 and 25 of a section each name a set of headers and footers (type 10143). In a set, field 1 lists the header and field 2 the footer, each as three text records in the order left, centre, right (confirmed by writing text into them, 0327; an empty one has no field 3). A plain document uses the set in field 25. When section field 19 is 1, left-hand pages use the set in field 24 instead, confirmed by writing it (0016, 0018, 0019, 0386). When section field 18 is 1, the section's first page uses the set in field 23, confirmed by writing (0362).

Other section fields hold switches from the Section tab of Pages' Document sidebar. Likely (0017)

The document-wide Facing pages setting is field 34 of the type-10012 record, which also holds the creation time and template name and is probably the document's settings. Confirmed by writing it (0017, 0300)
