Record types

Every record type the specification names, 88 in all, with the sections that describe it. Types are the numbers in field 2.1 of a record's header (Container). The same number means the same kind of record in Pages, Keynote and Numbers wherever the spec has compared them, but most types have been seen in one app only. What it is comes from the type tables in the Keynote and Numbers chapters where there is one; otherwise it is the first sentence of the spec that names the type, shown in grey, for context only. The linked sections give the rules, with their confidence. Experiments lists those that name the type, as evidence.

This page is generated from the specification's Markdown each time the site is built. Link to a type as types.html#type-6001.
