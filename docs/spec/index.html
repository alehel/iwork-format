Specification#

Five chapters describe what Pages, Keynote and Numbers documents share, each built on the one before, and one chapter per app describes what is its own. Every finding links to the experiments that support it, and carries a confidence level (see CONTRIBUTING.md). The experiments by topic list the evidence behind each section.

ChapterCoversWhat is known so far
1. ContainerHow a document is packaged: ZIP or folder, its parts, how they're encoded, how objects refer to each otherChunks, records, references, part and data file lists and password protection are confirmed, and so is writing documents back. What the view state holds is mostly open
2. TextThe document's text, paragraphs and breaks, and the runs that apply styles, links, fields and changesText, positions, breaks, run tables, links, comments, fields and tracked changes are confirmed. Right-to-left paragraphs set in the app are unknown
3. StylesParagraph, character and list styles, fonts, coloursMost properties and how styles inherit are confirmed by writing them; underline, strikethrough and some line spacing are likely
4. TablesTable models, tiles, cells, formats, formulas, merged cellsCells, formats, formulas and every function number, merges, sizes and headers are confirmed; control settings and parts of formulas are likely
5. Drawables, media and chartsImages, text boxes, shapes, groups, sounds, movies, chartsGeometry, borders, fills, groups, masks, captions, media and chart data and options are confirmed, and so are the page an object placed on the page is drawn on and the text wrap's spacing; Move with Text offsets and the other wrap settings are likely; some outline forms, gradients and Inline with Text are open
PagesPage setup, sections, headers and footersPaper, margins, sections, headers and footers are confirmed; page-layout documents are likely
KeynoteSlides, layouts, notes, builds, transitions, backgroundsSlides and their order, layouts, notes, transitions, builds and presentation settings are mapped, many confirmed by writing them
NumbersSheets, the way to a table's cells, categories, pivot tables, filters, highlighting, the calculation engineSheets and tables are confirmed; categories, pivot tables, filters and highlighting in part; what the engine's owners are for is likely

Every write so far changes a document the apps saved; making one from nothing is not yet shown.

App releases#

The spec describes the format as the newest apps write it, Pages, Numbers and Keynote 16.0. A version note stands where something doesn't hold for every release checked; releases.md lists the releases, how to tell which one saved a document, and everything each one changed.

Features and scope#

features.md defines what full support for each app means: the read, edit, create, render, calculate and play capabilities, the profiles built from them, and the releases and producers in scope. It lists every feature with one owning issue, and shows for each app which capabilities its experiments have shown, worked out from the experiments themselves. Its coverage is also published as features.json.
