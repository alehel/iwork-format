0050: A shape#

App release: 15.4

Status: run

0049 found that a Pages text box is a shape of type 2011. This experiment places a default shape with text, to see what tells a shape apart from a text box.

Setup#

Pages15.4 (build M15.4-7051.0.79-2)
macOS26.5.2 (25F84)
Date2026-11-09
Baselinesamples/0020/plain.pages; experiment 0049

Recipe#

mkdir -p samples/0050
osascript recipes/0050-pages-shape.applescript "$PWD/samples/0050/shape.pages"

The recipe makes a document with the body text one, then a shape on page 1 with the object text shape.

Observation#

The same records were added as for the text box in 0049: one of type 2011, a text record, and two of type 3097. The type-2011 record differs from the text box's in:

Text box (0049)Shape
1.1.2, size250 × 128100 × 100
1.2, style1731559, type 2025, textbox-0-shapestyle1731553, type 2025, shape-0-shapestyle
Text's paragraph style (field 5)1731511 (Body)1731523

Corrected 2026-11-25: the records also differ in position (1.1.1), in the path's size (1.3.5.2) and in field 6, 1 for the text box and 0 for the shape.

Conclusion#

A shape and a text box are the same kind of object, type 2011. They differ in their shape style (type 2025): shape-0-shapestyle against textbox-0-shapestyle. Their default sizes differ too, as does the paragraph style their text starts with. A reader draws both from their path (1.3) and style, so it doesn't need to tell them apart.

Evidence#

2021#5 11.1: 0 → 1 says that field 11.1 of the type-2021 record with ID 5 held 0 and holds 1; without an ID, that some record of the type does. = is a value it holds, ≠ one it doesn't, ~ bytes it contains, and ×2 how often a field occurs. These statements were checked against the documents by script (fixtures/evidence.py); only means that nothing else differs but the previews. What the app showed, and what follows from it, is the experiment's own.

Confidence#

Likely: shapes and text boxes are both type 2011, told apart only by style and content. Shape styles are type 2025.

Unknown: the shape style's fields, such as fill and stroke. Follow-up: give a shape a fill colour (experiment 0077).
