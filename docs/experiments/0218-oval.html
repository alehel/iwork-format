0218: An oval#

Status: run

0217 read a rectangle's outline as a path of move, line and close elements. This experiment inserts an oval, to see how curves are stored.

Setup#

Pages15.4 (build M15.4-7051.0.79-2), in Norwegian
macOS26.5.2 (25F84)
Date2026-11-09
BaselineExperiment 0217

Recipe#

  1. Make a document with the body text One: ``bash osascript -e 'tell application "Pages" to set body text of (make new document) to "One"'
  2. Choose Insert → Shape → Oval (Sett inn → Figur → Oval).
  3. Save it as samples/0218/oval.pages.

Observation#

Inserted from the menu, the oval goes into the text. The body becomes One and U+FFFC, and the shape's field 1.2 names the body (1732539). It is 100 × 100.

Its outline is a field-1.3.5 path with a natural size of 100 × 100 and seven elements, of kinds 1, 4, 4, 4, 4, 5, 1. The first two:

{ 1: 1, 2: (85.355, 14.645) }                          ← move to
{ 1: 4, 2: (104.882, 34.171), 2: (104.882, 65.829),
        2: (85.355, 85.355) }                          ← curve to

Conclusion#

Element kind 4 is a cubic Bézier curve with three points: two control points and the end point. The oval is four such curves. It starts at 45° on the circle, (50 + 50 cos 45°, 50 − 50 sin 45°), not at a quadrant point. Its control points lie outside the 100 × 100 box. As in 0217, the path ends with a close (5) and a final move (1) back to the start.

Shapes inserted from the menu sit in the text, like a table inserted from the menu (0052).

Confidence#

Likely: path element kind 4 is a cubic curve with its two control points before its end point.
