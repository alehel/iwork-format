0283: An advanced linear gradient#

App release: 15.4

Status: run

0275 found gradient field 4 set to 1 on a radial gradient made in the advanced editor, and 0 on the simple linear gradient of 0260. That left two explanations: field 4 marks the advanced editor, or it goes with the radial kind. This experiment makes a linear gradient in the advanced editor.

Setup#

Pages15.4 (build M15.4-7051.0.79-2), in Norwegian
macOS26.5.2 (25F84)
Date2026-11-09
BaselineExperiments 0260 and 0275

Recipe#

mkdir -p samples/0283
osascript recipes/0213-pages-shape.applescript 1

The new shape is left selected. With Pages in front, choose Advanced Gradient Fill from the Fill pop-up and leave it linear, at 270°. Save as samples/0283/advanced-linear.pages.

Conclusion#

Gradient field 4 is 1 for a gradient made in the advanced editor and 0 for the simple one, whatever its kind. Only field 1 says whether the gradient is linear or radial. A reader can ignore field 4: it only tells Pages which editor to show.

Evidence#

2021#5 11.1: 0 → 1 says that field 11.1 of the type-2021 record with ID 5 held 0 and holds 1; without an ID, that some record of the type does. = is a value it holds, ≠ one it doesn't, ~ bytes it contains, and ×2 how often a field occurs. These statements were checked against the documents by script (fixtures/evidence.py); only means that nothing else differs but the previews.
