0241: The zoom level#

Status: run

ViewState.iwa changes with almost every edit, but its contents haven't been read. This experiment changes only the zoom, to find what the view state records.

Setup#

Pages15.4 (build M15.4-7051.0.79-2), in Norwegian
macOS26.5.2 (25F84)
Date2026-11-09
Baselinesamples/0236/plain.pages, a new document at the default zoom of 125%

Recipe#

  1. Make a document with the body text One: ``bash osascript -e 'tell application "Pages" to set body text of (make new document) to "One"'
  2. Choose View → Zoom → Actual Size, then View → Zoom → Zoom In (Vis → Zoom → Faktisk størrelse, then Zoom inn). The toolbar shows 200%.
  3. Save it as samples/0241/zoom-200.pages.

Observation#

Apart from IDs, ViewState.iwa differs from the baseline in one record, of type 10133:

Field125%200%
7, a point(582.4, 799.2)(364, 499.5)
151.252.0

Nothing else in the document changes.

Conclusion#

The type-10133 record in ViewState.iwa holds the window's view of the document. Field 15 is the zoom as a scale factor. Field 7 is a point that shrinks as the zoom grows, as a point measured in the zoomed view would. It is probably the visible area's size or centre in document points: 582.4 × 1.25 and 364 × 2 are both 728, the width of the window's document area. A reader can ignore the view state. An app that opens documents could use it to restore the zoom.

Confidence#

Likely: field 15 of the type-10133 view state is the zoom.

Unknown: the exact meaning of field 7.
