0458: A series' line in a line chart#

App release: 15.4

Status: run

A series style's colour properties 6 to 17 are fills, and a line chart's line took its colour from none of them (0457). The style also has eleven stroke properties, 4, 5 and 45 to 53, each a stroke as for shapes: a colour in 1, a width in 2 and a pattern in 6, whose kind is 1 for solid and 2 for none (0250). This experiment writes red into each solid blue stroke and looks at the line.

Setup#

Keynote15.4, in Norwegian
macOS26.5.2 (25F84)
Date2026-11-18
Inputsamples/0296/baseline.key, with chart 2655552 made a line chart (10000.1 = 3). In the first series' style, 2651484, the strokes are black (4, 5), grey and none (45, 49), black and none (46, 52), and solid blue of width 1 (47, 50), 6 (48, 51) and 3 (53)
Writerrecipes/0302-set-path.py; exported with recipes/0372-in-app.sh and read with recipes/0384-pdf-colours.swift

Recipe#

mkdir -p samples/0458
O=samples/0458
python3 -I recipes/0302-set-path.py samples/0296/baseline.key $O/line.key 2655552 10000.1 varint 3
for k in 47 48 50 51 53; do
  python3 -I recipes/0302-set-path.py $O/line.key $O/line-$k.key 2651484 \
    10000.$k.1.3 float 1 10000.$k.1.4 float 0 10000.$k.1.5 float 0 10000.$k.1.12 varint 0
  sh recipes/0372-in-app.sh Keynote $O/line-$k.key "export d to POSIX file \"$PWD/$O/line-$k.pdf\" as PDF"
  swift recipes/0384-pdf-colours.swift $O/line-$k.pdf $(for y in $(seq 630 680); do printf "990,%s " $y; done)
done

The points run down a column through the first series' line, every point from y = 630 to 680.

Observation#

Stroke written redRed pointsBlue points
47 (width 1)06
48 (width 6)60
50 (width 1)06
51 (width 6)06
53 (width 3)06

Conclusion#

Stroke property 48 draws a line chart's line: written red, the whole line is red, and the line is 6 points thick where it crosses the column, the stroke's width. The other solid strokes didn't change it; with their widths and the fills of 0457 they are probably the outlines and lines of other chart types. A reader drawing a line chart should take each series' line from its style's property 48.

Evidence#

2021#5 11.1: 0 → 1 says that field 11.1 of the type-2021 record with ID 5 held 0 and holds 1; without an ID, that some record of the type does. = is a value it holds, ≠ one it doesn't, ~ bytes it contains, and ×2 how often a field occurs. These statements were checked against the documents by script (fixtures/evidence.py); only means that nothing else differs but the previews.
