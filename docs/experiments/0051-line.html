0051: A line#

Status: run

This experiment draws a line from one point to another on a Pages page, to see how a line's end points are stored.

Setup#

Pages15.4 (build M15.4-7051.0.79-2)
macOS26.5.2 (25F84)
Date2026-11-09
Baselinesamples/0020/plain.pages; experiments 0049 and 0050

Recipe#

mkdir -p samples/0051
osascript recipes/0051-pages-line.applescript "$PWD/samples/0051/line.pages"

The recipe makes a document with the body text one, then a line on page 1 from (100, 100) to (300, 200).

Observation#

The line is a record of type 2011, like a text box or shape. It also has an empty type-2001 text record and two type-3097 records. Its geometry (field 1.1):

1.1.1: x 88.2,  y 150.0
1.1.2: width 223.6, height 0.0
1.1.4: 333.43494

Its style (1.2) is 1731547, type 2025, named line-0-shapestyle, and its path (1.3) is 52 bytes, against 104 for a rectangle.

Conclusion#

A line is a type-2011 shape whose geometry is a box of zero height:

  • Width: the line's length, √(200² + 100²) = 223.6.
  • Rotation: field 1.1.4 holds the rotation in degrees. 333.43° is −26.57°, the angle from (100, 100) to (300, 200), measured clockwise with y pointing down.
  • Position: field 1.1.1 is where the unrotated box starts. Here that's the line's midpoint (200, 150) minus half its length on x.

So a reader rotates the box about its centre to find the end points: (200 ± 111.8 · cos 26.57°, 150 ± 111.8 · sin 26.57°) = (100, 100) and (300, 200).

Geometry field 1.1.4 has been 0 for every other object so far, so it is probably the rotation of any drawable.

Confidence#

Likely:

  • A line is type 2011 with the line-0-shapestyle style.
  • Geometry field 1.1.4 is the rotation in degrees.
  • The box is rotated about its centre.

Unknown: the direction of rotation. Follow-up: rotate an image by a known angle (experiment 0056).
