0387: Writing same as previous section#

App release: 15.4

Status: run

Each section (type 10011) names its own header-and-footer sets, in fields 23, 24 and 25. Field 17 is the Same as previous section switch, 1 by default (0017). This experiment writes header text into two sections and turns the second section's switch off, then reads the exported PDF.

Setup#

Pages15.4, in Norwegian
macOS26.5.2 (25F84)
Date2026-11-17
Inputsamples/0361/char-only-resaved.pages: first, a section break, then second, so two pages and two sections, 1732660 and 1732682, both with field 17 = 1 and empty headers. The first header box of each section's right-hand set (field 25) is text record 1732676 and 1732698
Writerrecipes/0302-set-path.py; exported with recipes/0372-in-app.sh and read with recipes/0374-pdf-text.swift

Recipe#

mkdir -p samples/0387
R=recipes/0302-set-path.py
F=samples/0361/char-only-resaved.pages
O=samples/0387
python3 -I $R $F $O/first-only.pages 1732676 3 string "First header"
python3 -I $R $O/first-only.pages $O/first-only-own.pages 1732682 17 varint 0
python3 -I $R $O/first-only.pages $O/both.pages 1732698 3 string "Second header"
python3 -I $R $O/both.pages $O/both-own.pages 1732682 17 varint 0
for f in first-only first-only-own both both-own; do
  sh recipes/0372-in-app.sh Pages $O/$f.pages "export d to POSIX file \"$PWD/$O/$f.pdf\" as PDF"
  swift recipes/0374-pdf-text.swift $O/$f.pdf
done

Conclusion#

With field 17 at 1, a section's pages use the previous section's headers and footers, and its own sets are kept but ignored, even when they hold text. With field 17 at 0, the section uses its own sets. A reader must follow field 17 back to the section whose sets are actually used.

Evidence#

2021#5 11.1: 0 → 1 says that field 11.1 of the type-2021 record with ID 5 held 0 and holds 1; without an ID, that some record of the type does. = is a value it holds, ≠ one it doesn't, ~ bytes it contains, and ×2 how often a field occurs. These statements were checked against the documents by script (fixtures/evidence.py); only means that nothing else differs but the previews.
