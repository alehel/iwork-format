0449: Writing a build's direction#

App release: 15.4

Status: run

A build's effect is in its field 4.18, with In, Out or Action in 4.18.1 for a build-in, build-out or action (0263, 0264). This experiment turns a build-in into a build-out by writing that text, and compares the exported stages with the slide without a build.

Setup#

Keynote15.4, in Norwegian
macOS26.5.2 (25F84)
Date2026-11-18
Inputsamples/theme/0257/build.key: a slide whose title builds in, build 2655727 with 4.18.1 = In and the effect apple:dissolve character. samples/theme/0257/plain.key: the same slide without a build
Writerrecipes/0302-set-path.py; exported with recipes/0372-in-app.sh and compared with the new recipes/0449-image-diff.swift

Recipe#

mkdir -p samples/0449
O=samples/0449
cp samples/theme/0257/plain.key $O/plain.key
python3 -I recipes/0302-set-path.py samples/theme/0257/build.key $O/out.key 2655727 4.18.1 string Out
for f in plain out; do
  mkdir -p $O/img-$f
  sh recipes/0372-in-app.sh Keynote $O/$f.key \
    "export d to POSIX file \"$PWD/$O/img-$f\" as slide images with properties {image format:PNG, all stages:true}"
done
swift recipes/0449-image-diff.swift $O/img-plain/*.png $O/img-out/*.png

Observation#

ImagesCompared with the plain slide
img-out.001.pngthe same: the title is shown
img-out.002.png2,253 sampled pixels differ: the title is gone

As a build-in (0448), the same build gave the opposite: no title in the first image, the title in the second.

Conclusion#

Field 4.18.1 decides the build's direction: written Out, the title is on the slide at first and the build takes it away, where In brings it on. The effect, its identifier in 4.18.2, stays the same, so the same dissolve plays either way. A reader showing a slide's starting or final state must apply builds by their direction.

Confidence#

Confirmed: field 4.18.1 as the build's direction, by writing Out into a build-in.
