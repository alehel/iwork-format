0171: A slider#

App release: 15.4

Status: run

This experiment gives a cell the slider format.

Setup#

Numbers15.4 (build M15.4-7051.0.79-2)
macOS26.5.2 (25F84)
Date2026-11-09
BaselineExperiment 0036, formats.numbers

Recipe#

mkdir -p samples/0171
osascript recipes/0169-numbers-controls.applescript slider "$PWD/samples/0171/slider.numbers"

Cell B2 of table 1 is decoded from Index/Tables/Tile.iwa as in 0036.

Observation#

B2 is a number cell with flags 0x00003401, like the rating, holding the decimal128 50. The cell-control entry is:

12: { 1: 5, 3: 1.0, 4: 100.0, 5: 1.0 }

and the format list's entry is 256 (number), with a field 6.2 of 253.

Conclusion#

A slider is a number with control kind 5, ranging here from 1 to 100 in steps of 1. Unlike a rating, its number format is an ordinary one. The cell's flags are the same as for a rating, so only the control entry tells them apart.

Evidence#

2021#5 11.1: 0 → 1 says that field 11.1 of the type-2021 record with ID 5 held 0 and holds 1; without an ID, that some record of the type does. = is a value it holds, ≠ one it doesn't, ~ bytes it contains, and ×2 how often a field occurs. These statements were checked against the documents by script (fixtures/evidence.py); only means that nothing else differs but the previews. What the app showed, and what follows from it, is the experiment's own.
