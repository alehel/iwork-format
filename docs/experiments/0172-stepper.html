0172: A stepper#

Status: run

This experiment gives a cell the stepper format.

Setup#

Numbers15.4 (build M15.4-7051.0.79-2)
macOS26.5.2 (25F84)
Date2026-11-09
BaselineExperiment 0171

Recipe#

mkdir -p samples/0172
osascript recipes/0169-numbers-controls.applescript stepper "$PWD/samples/0172/stepper.numbers"

Cell B2 of table 1 is decoded from Index/Tables/Tile.iwa as in 0036.

Observation#

B2 has the same flags as the slider in 0171, holding 5. The cell-control entry is { 1: 4, 3: 1.0, 4: 100.0, 5: 1.0 }, the same as the slider's apart from field 1, and the format list's entry is the same.

Conclusion#

A stepper is control kind 4. Sliders and steppers have the same range defaults and number format, so a reader that can't draw either control can show the number.
