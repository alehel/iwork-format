0351: Writing a character style run#

App release: 15.4

Status: run

A text's run table 8 attaches character styles (type 2021) to ranges: each entry has a position in field 1 and a style reference in field 2, and an entry without one ends the previous style (0008). This experiment writes such a table and asks Pages.

Setup#

Pages15.4, in Norwegian
macOS26.5.2 (25F84)
Date2026-11-10
Inputsamples/0002/hello.pages with its body text replaced by plain bold; the template's character style Framhevet (Emphasis, record 1731541) sets only 11.1 = 1, bold
WritersThe writer of 0287 for the text, recipes/0351-add-run.py for the run table

Recipe#

mkdir -p samples/0351
python3 -I recipes/0287-iwa-writer.py samples/0002/hello.pages samples/0351/plain.pages --text 1732539 "plain bold"
python3 -I recipes/0351-add-run.py samples/0351/plain.pages samples/0351/bold.pages 1732539 8 0 0 6 1731541

The run table gets two entries: position 0 with no style, and position 6 (the start of bold) with Framhevet. Pages opened each file on its own, read each word's font through AppleScript, exported it as PDF and saved the written file again.

Observation#

FileWord 1Word 2Line's ink
plain.pagesHelveticaNeueHelveticaNeue57.8 – 104.2
bold.pagesHelveticaNeueHelveticaNeue-Bold57.8 – 105.8

Saved again, the run table holds the same two entries.

Conclusion#

A run table entry applies its style from its position to the next entry, and an entry with no style means none. A writer can style part of a text by adding entries, without touching the text or the paragraph runs. A named character style that sets only bold makes the paragraph style's font bold.

Evidence#

2021#5 11.1: 0 → 1 says that field 11.1 of the type-2021 record with ID 5 held 0 and holds 1; without an ID, that some record of the type does. = is a value it holds, ≠ one it doesn't, ~ bytes it contains, and ×2 how often a field occurs. These statements were checked against the documents by script (fixtures/evidence.py); only means that nothing else differs but the previews. What the app showed, and what follows from it, is the experiment's own.
