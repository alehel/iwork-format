0236: Hyphenation#

App release: 15.4

Status: run

Pages can hyphenate a whole document from the Document sidebar. This experiment turns that on, to find where document-wide settings are stored. 0017 found facing pages in a type-10012 record, which seems to hold such settings.

Setup#

Pages15.4 (build M15.4-7051.0.79-2), in Norwegian
macOS26.5.2 (25F84)
Date2026-11-09
Baselinesamples/0236/plain.pages, a new document with the body text One

Recipe#

  1. Make a document with the body text One: 
    osascript -e 'tell application "Pages" to set body text of (make new document) to "One"'
  2. Open the Document sidebar (the Dokument button in the toolbar) and tick Use Hyphenation in Document (Bruk orddeling i dokument).
  3. Save it as samples/0236/hyphenation.pages.

Observation#

Apart from the creation time stored as text in field 26, the only record that changes in Document.iwa is the one of type 10012:

9: 0 → 1

No paragraph style changes.

Conclusion#

Field 9 of the type-10012 document settings turns on hyphenation for the whole document. It is a document setting, not a property of the paragraph styles, so a reader that lays out text should hyphenate every paragraph when it is 1.

Evidence#

2021#5 11.1: 0 → 1 says that field 11.1 of the type-2021 record with ID 5 held 0 and holds 1; without an ID, that some record of the type does. = is a value it holds, ≠ one it doesn't, ~ bytes it contains, and ×2 how often a field occurs. These statements were checked against the documents by script (fixtures/evidence.py); only means that nothing else differs but the previews. What the app showed, and what follows from it, is the experiment's own.
