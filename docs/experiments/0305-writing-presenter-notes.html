0305: Writing presenter notes, and the kinds of text storage#

Status: run

0039 found a slide's presenter notes in a text storage (type 2001) of their own. This experiment replaces that text by writing and asks Keynote for the notes. It also surveys field 1 of every text storage in the samples, which marks what a text is for.

Setup#

Keynote15.4
macOS26.5.2 (25F84)
Date2026-11-10
Inputsamples/theme/0039/notes.key: one slide whose notes are notes here, in the test theme
WriterThe writer of 0287, whose --text option sets a text storage's field 3

Recipe#

mkdir -p samples/0305
cp samples/theme/0039/notes.key samples/0305/original.key
python3 -I recipes/0287-iwa-writer.py samples/0305/original.key samples/0305/written.key \
  --text 2655508 "Notes written by a script"

Record 2655508, in Index/Slide.iwa, is the text storage holding notes here. Keynote opened each file on its own through Launch Services (0302), read presenter notes of slide 1, and saved the written file again. A script then counted field 1 of every type-2001 record in the samples, by app.

Observation#

Keynote reads the original's notes as notes here and the written file's as Notes written by a script. The resaved file keeps the new text in the same record.

Field 1 of the type-2001 records:

Field 1WhereCount
0Pages: the body191
1Pages: headers and footers (0003); Numbers: text in Document.iwa3,456; 1,236
2Pages: a footnote's text, in 00411
4Keynote: presenter notes, one per slide136
7Pages: a table of contents, in 02021
AbsentText in shapes, text boxes, placeholders and table cells6,664

Conclusion#

A slide's presenter notes are an ordinary text storage, and writing its field 3 changes them. Field 1 of a text storage says what the text is for: 0 a document body, 1 a header or footer, 2 a footnote, 4 presenter notes and 7 a table of contents, while text inside objects leaves it out. What 1 means in Numbers, where it is common, isn't clear from this survey.

Confidence#

Confirmed: presenter notes are written through their text storage's field 3.

Likely: field 1 values 0, 1, 2, 4 and 7.
