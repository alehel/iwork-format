0120: Fewer rows#

App release: 15.4

Status: run

0020 read the number of rows from table model field 6. This experiment changes it.

Setup#

Numbers15.4 (build M15.4-7051.0.79-2)
macOS26.5.2 (25F84)
Date2026-11-09
BaselineExperiment 0024, empty-a.numbers

Recipe#

mkdir -p samples/0120
osascript recipes/0113-numbers-variants.applescript "$PWD/samples/0120/fewerrows.numbers" fewerrows

Observation#

The recipe sets the table's row count to 5. Model field 6 changed from 22 to 5. The drawable's size (494 × 231) didn't change.

Conclusion#

Model field 6 is the number of rows. As in 0059, the drawable's stored size wasn't updated.

Confidence#

Confirmed: model field 6 is the row count (0020 and this experiment).
