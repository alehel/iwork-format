0120: Fewer rows#

Status: run

0020 read the number of rows from table model field 6. This experiment changes it.

Observation#

The recipe sets the table's row count to 5. Model field 6 changed from 22 to 5. The drawable's size (494 × 231) didn't change.

Conclusion#

Model field 6 is the number of rows. As in 0059, the drawable's stored size wasn't updated.
